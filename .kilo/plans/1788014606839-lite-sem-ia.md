# Plano: branch `lite-sem-ia` (remover IA, manter features determinísticas)

## Objetivo

Criar a branch `lite-sem-ia` a partir de `go-backend` com **todas as features
determinísticas mantidas** (chat, mensagens repetidas, presentes, curtidas,
shares, ranking, relatório, metas, perfil, admin, moderação por flag) e **sem
nenhum componente de IA**, para rodar no Raspberry Pi via Docker arm64 enxuto.

A detecção de mensagens repetidas em <1 minuto **já existe** e é determinística
(`internal/monitor/monitor.go` — `handleChatMessage`, `repeatWindowMs = 60000`,
`repeatsRequired = 3`, categoria `REPETICAO`). Ela permanece intacta.

- `git checkout -b lite-sem-ia go-backend`
- Confirmar ponto de partida: working tree limpo (já está, `go-backend` à frente
  de `origin` em 5 commits).

## Riscos / Observações

- Remover o campo `LLMCorrelate` exige ajustar `correlation_test.go`; o restante
  da correlação presente↔chat continua determinístico (heurística).
- O relatório (`internal/report`) já é determinístico em Go (o comentário que
  cita "LLM" está desatualizado) — manter como está.
- `feedback.db`, `data.db` e os binários `main`/`tiktok-live-monitor` na raiz são
  artefatos locais (gitignored) e não entram na branch.
- Se a limpeza de `internal/config` (Passo 1.7) quebrar o build, revertê-la é
  seguro (o pacote é inerte em runtime).
